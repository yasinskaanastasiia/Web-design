# Minesweeper UI

Лабораторна робота з HTML та CSS.

## Опис
Реалізовано візуальну частину гри Minesweeper:
- Хедер з таймером
- Лічильник прапорців
- Кнопка "New Game"
- Ігрове поле 10×10

## Технології
- HTML5
- CSS3
